# 入服欢迎 0.0.4
> 玩家进入/离开服务器时按配置延迟发送欢迎、提示或告别指令

收录自 ToolDelta 官方插件市场，原作者 wling；本仓库有标准化修改。

## 功能
- **进服欢迎**：玩家登录后等待 `登录时延迟发送` 秒，再按顺序执行 `登录时发送指令` 列表中的每条指令。
- **退服告别**：玩家退出时立即执行 `登出时发送指令` 列表中的指令。
- **玩家名替换**：指令中的 `[target_player]` 会替换为进服/退服玩家名，默认文本还带 `@` 前缀，可直接用于 tellraw 选择器。
- **默认效果**：进服提示玩家在聊天栏发送 `.help` 调出系统面板；退服用 tellraw 向全服广播 `Bye~ <玩家名>`。
- **无数据与无指令**：插件不生成数据文件，也没有手动指令，只监听玩家进服/退服事件。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `聊天栏菜单` | 0.1.13 | 默认登录提示引导玩家使用 `.help`；插件代码本身不调用其 API，未安装时仅该提示无效 |

## 安装
1. 将 `入服欢迎/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/入服欢迎.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `登录时发送指令` | 1 条 tellraw 提示 `.help` | 玩家进服后延迟执行，列表项替换 `[target_player]` 后交给机器人执行 |
| `登录时延迟发送` | `10` | 进服后延迟秒数，由独立线程 `time.sleep` 控制 |
| `登出时发送指令` | 1 条 tellraw 广播 `Bye~ @[target_player]` | 玩家退服时立即执行 |

两个指令列表都按列表顺序逐条执行，建议每项写完整的游戏指令（默认项带前导 `/`）。

## 指令
本插件无手动指令；玩家进服/退服自动触发上面配置的指令。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 无第三方 Python 库，无数据文件。
- 指令通过机器人 `sendwocmd` 执行，机器人需要有 `tellraw` 等对应权限。
- 进服延迟在独立线程中执行，不阻塞主线程；服务器玩家较多时需要注意大量同时进服产生的指令量。

## 版本记录

## 说明
- `[target_player]` 是唯一支持的占位符；默认退服文案写成 `@[target_player]`，替换后形如 `@Steve`。
- 延迟期间玩家若已退出，进服指令仍会尝试执行一次（机器人执行结果可忽略）。
- 若未安装 `聊天栏菜单`，默认提示中的 `.help` 不会生效，建议修改 `登录时发送指令` 换成自己的欢迎语。
- 欢迎文案和指令完全由配置决定，可与其它插件的事件提示重复，安装后建议先检查是否与已有进服提示冲突。
