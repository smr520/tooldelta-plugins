# 签到系统 0.0.3
> 聊天栏输入 `#签到` 领取奖励，支持冷却时间、奖励指令与随机签到语配置

收录自 ToolDelta 官方插件市场，原作者 权威-马牛逼；本仓库有标准化修改。

## 功能
- **聊天栏签到**：玩家在聊天栏发送 `#签到` 即触发签到，无需任何权限或菜单。
- **冷却控制**：距上次签到不足 `签到间隔时间（分钟）` 时只提示剩余分钟数，不重复发放奖励；默认 `1440` 分钟（按上次签到时间滚动计算，不是自然日 00:00 重置）。
- **奖励发放**：执行配置项 `每日奖励` 中的指令，`[player]` 会替换为玩家名；默认指令为 `give [player] bread 5`。
- **随机提示语**：从 `签到语列表` 随机抽一条文案，配合 `签到成功提示` 的 `{sign_msg}`、`{reward_desc}` 占位符显示；冷却中则使用 `已签到提示` 的 `{remaining}`。
- **数据持久化**：按玩家 UUID 记录最后签到时间与日期，保存到 `插件数据文件/每日签到/sign_in_data.json`，重启后冷却状态保留。
- **异常兜底**：奖励指令执行失败时向玩家提示「签到失败，请联系管理员」，并在控制台输出错误信息。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `聊天栏菜单` | 0.4.0 | 注册 `.签到` 菜单项，让签到出现在游戏内 `.help` 菜单里；未安装时仍可用 `#签到` |

## 安装
1. 将 `签到系统/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/每日签到.json`（首次加载自动生成；文件名取自代码内的插件名 `每日签到`，不是目录名）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `每日奖励` | `"give [player] bread 5"` | 签到成功后执行的游戏指令，`[player]` 为玩家名 |
| `签到间隔时间（分钟）` | `1440` | 两次签到的最小间隔（分钟） |
| `签到语列表` | 99 条默认文案 | 随机签到语，可增删替换 |
| `已签到提示` | `"§a你今天已经签到过了，冷却剩余：{remaining}分钟"` | 冷却中的提示，`{remaining}` 为剩余分钟数 |
| `签到成功提示` | `"{sign_msg} 获得奖励：{reward_desc}"` | 签到成功提示，`{sign_msg}` 为随机签到语，`{reward_desc}` 为奖励描述 |

数据文件路径：`插件数据文件/每日签到/sign_in_data.json`，结构为 `{"<玩家UUID>": {"last_sign_time": 时间戳, "last_sign_date": "年-月-日"}}`。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.签到` | 所有玩家 | 聊天栏菜单项（会出现在 `.help` 里），签到并领取奖励 |
| 聊天栏 | `#签到` | 所有玩家 | 兼容旧写法，效果相同；冷却中提示剩余时间 |

签到同时支持 `.签到` 菜单项与 `#签到`，两者共用冷却与奖励逻辑。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 无第三方 Python 库；`聊天栏菜单` 为可选前置（未安装时只支持 `#签到`）。
- 通过 `ListenChat` 监听聊天内容，聊天栏菜单类插件不会拦截 `#签到`。
- 奖励指令由机器人执行，需有 `give` 等对应权限；玩家 UUID 由框架提供，同一账号改名后签到记录仍保留。

## 说明
- 目录名为 `签到系统`，插件 ID 与配置/数据目录键为 `每日签到`，安装后请在 `插件配置文件/每日签到.json` 中修改配置。
- `签到语列表` 实际有 99 条，`datas.json` 描述写「100种签到语」，以实际列表数量为准。
- `{reward_desc}` 的生成方式是取 `每日奖励` 按空格拆分后的最后两项并反转（数量 物品ID），建议保持 `give <玩家> <物品ID> <数量>` 的写法，否则奖励描述会显示错乱或处理报错。
- 若需按自然日重置，可将 `签到间隔时间（分钟）` 改为适合的固定分钟数，或另行修改代码逻辑。
