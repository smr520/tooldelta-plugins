# 公会系统 0.1.1
> 玩家创建公会的系统：成员职位、经验等级、据点、仓库、任务与效果增益

收录自 ToolDelta 官方插件市场，原作者 星林 & 夏至；本仓库有标准化修改。

## 功能
- **公会创建与解散**：创建消耗 `5000` 积分（记分板 `money`），公会名 2~20 字且不能含 `& < > " ' \ / |`；会长可解散公会，会长不能自行退出，只能解散或转让。
- **加入与退出**：加入时按公会名模糊搜索，向有邀请权限的在线成员发送申请，对方回复「同意」/「拒绝」；普通成员可自由退出。
- **职位与成员管理**：会长、副会长、长老、成员四级，权限表见 `Config.PERMISSIONS`；会长可设职位、踢人、转让会长，副会长可管理长老与成员。
- **经验与等级**：按在线成员数每 `600` 秒为公会加经验（每人 `10` 点），升级门槛 `100 * 2^n`，最高 10 级；捐献物品会同时增加贡献度与公会经验。
- **公会据点**：会长记录当前坐标与维度为据点，成员可从据点菜单传送过去。
- **公会仓库**：成员可按默认价目表或自定义贡献点价格上架物品，其他成员用贡献点购买；容量 `54` 格，支持中文名、别名和模糊匹配。
- **效果增益**：用钻石为全公会购买 速度、急迫、力量、抗性提升、生命恢复、夜视、跳跃提升，等级 1/2 分别需要 `10`/`20` 钻石；在线成员每 5 分钟自动续期。
- **公会任务、排行与公告**：任务支持收集/击杀/建造/交易四类并可领奖励；排行支持等级、成员数、贡献、活跃度；公告最长 200 字，日志保留最近 50 条。
- **公会聊天频道**：`.gc` 无参数切换公会聊天模式（该模式下聊天内容只发给在线公会成员），带消息则直接发送一条公会消息。

## 安装
1. 将 `公会系统/` 整个目录复制到实例的 `插件文件/ToolDelta类式插件/`（含 `guild/` 子包，不能只拷 `__init__.py`）；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
无 JSON 配置文件，开箱即用；可调参数集中在 `guild/config.py` 的 `Config` 类中，修改后需 `reload` 才生效。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `GUILD_CREATION_COST` | `5000` | 创建公会所需积分 |
| `MAX_GUILD_MEMBERS` | `30` | 单个公会成员上限 |
| `GUILD_SCOREBOARD` | `"money"` | 积分使用的记分板名称；插件启动时会尝试创建 `money`（dummy，显示名「积分」），实际积分由服务器的经济系统提供 |
| `GUILD_LEVELS` | `[100, 200, 400, ...]` | 1→10 级升级门槛（`100 * 2^i`） |
| `EXP_PER_ONLINE_MEMBER` / `EXP_UPDATE_INTERVAL` | `10` / `600` | 每人每 600 秒为公会提供的经验 |
| `GUILD_FUNCTION_VAULT` 等 6 个开关 | `true` | 仓库、据点、捐献、任务、效果、排行功能开关 |
| `PERMISSIONS` | 见文件 | 各职位可用权限（`owner` 为 `all`） |
| `VAULT_INITIAL_SLOTS` | `54` | 公会仓库容量（代码注释写「固定10000格」，以本值为准） |
| `EFFECTS_CONFIG` | 7 种效果 | 效果名称、等级与钻石价格 |
| `DEFAULT_ITEM_VALUES` / `CHINESE_ITEM_NAMES` / `ITEM_ALIASES` | 见文件 | 物品贡献点价值表、中文名映射、别名表 |

数据文件：`插件数据文件/公会系统/公会数据文件.json`（首次写入数据时自动生成，保存公会、成员、仓库、任务、日志、效果等数据）。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.公会`、`.guild` | 所有玩家 | 打开公会主菜单 |
| 聊天栏 | `.gc` | 公会成员 | 切换公会聊天模式 / 公共聊天模式 |
| 聊天栏 | `.gc <消息>`、`.公会聊天 <消息>` | 公会成员 | 发送一条公会频道消息 |
| 聊天栏 | `.仓库出售 <物品名> [数量] [价格]`、`.出售 ...` | 公会成员 | 按默认价目表出售物品到公会仓库 |
| 聊天栏 | `.自定义出售 <物品名> <数量> <价格>` | 公会成员 | 按自定义贡献点价格上架物品 |
| 聊天栏 | `.物品列表`、`.支持物品` | 所有玩家 | 查看支持的中文物品名称 |
| 聊天栏 | `.清理公会数据 确认清理` | 管理员 | 备份并清空所有公会数据（管理员名单硬编码在代码中） |
| 聊天栏 | `.调试公会菜单`、`.调试据点功能` | 所有玩家 | 输出菜单/据点调试信息 |
| 控制台 | `更新公会数据` | 控制台 | 修正数据文件中 `guild_id` 与外层键不一致的旧数据 |

`.公会` 主菜单的选项包括：创建、列表、查看、成员、日志、公告、加入、退出、管理、解散，以及按开关显示的仓库、据点、捐献、任务、效果、排行；输入选项文字执行，输入 `q` 退出，30 秒无输入视为超时。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 无第三方 Python 库；`guild/` 包内使用 `from guild.xxx import ...` 绝对导入，必须整目录安装。
- 积分读写依赖 `money` 记分板；仓库买卖、效果发放依赖原版 `clear`/`give`/`effect` 指令，机器人需要有对应权限。
- 部分功能仍处开发阶段：玩家行为任务进度监听（`on_player_action`）是空实现，`.清理公会数据` 仍引用旧缓存字段，详见「说明」。

## 说明
- 自 v0.1.0 起数据文件由 `guilds.json` 更名为 `公会数据文件.json`，结构有调整，不要直接复制旧数据文件，详见目录内 [错误处理.md](错误处理.md)。
- `.清理公会数据` 的「管理员名单」是代码内硬编码的占位实现（`Admin`/`管理员`/`op`），且清空逻辑引用了不存在的缓存字段与 `tempjson.save_and_write`，执行前请先手动备份数据文件。
- 公会仓库的「购买」流程引用了 `Config` 中不存在的 `VAULT_TRADE_TAX`，购买时会报错；使用前需在 `guild/config.py` 的 `Config` 类中补充该税率常量。
- 公会名创建失败时会把已扣除的积分加回；删除全部数据后需重新创建公会。
