# 玩家人数限制 0.0.3
> 玩家进服时检查在线人数，超过上限就踢出刚进服的非管理员玩家。

> 收录自 ToolDelta 官方插件市场，原作者 `SuperScript`；本仓库有标准化修改。

## 功能
- 监听玩家进服事件，每次有玩家加入时统计当前在线人数（`game_ctrl.allplayers`）。
- 在线人数严格大于配置的 `最大人数限制`，且新玩家不是管理员（`game_utils.is_op`）时，执行 `kick "<玩家名>" 已达到租赁服最大人数限制` 踢出该玩家。
- 踢出指令以控制台身份（`sendwocmd`）执行；默认上限 20 时，第 21 位进服的非管理员玩家会被踢出。
- 管理员进服不受人数限制；判定只发生在进服瞬间，已在服内的玩家不会被追溯踢出。
- 踢出目标使用玩家名（带引号，兼容含空格的玩家名）。
- 只做人数限制，不修改其它游戏规则；配置在插件加载时读取，修改后需要 `reload` 才生效。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `聊天栏菜单` | 0.4.0 | 注册 OP 专用 `.人数` 菜单项（出现在游戏内 `.help`）；可选，未安装时人数限制照样生效 |

## 安装
1. 将 `玩家人数限制/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/玩家人数限制.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `最大人数限制` | `20` | 允许的最大在线人数；玩家进服后人数超过该值即踢出非管理员新玩家 |

- 配置按整数读取；调低上限只影响之后进服的玩家，不会清理已在服内的玩家。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.人数` | OP | 查看当前在线人数与上限（出现在 `.help` 菜单） |

本插件没有控制台指令，也不注册群聊触发词。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库与 ToolDelta 内置 API（`game_utils.is_op`），无第三方库；
- 使用 `game_ctrl.allplayers` 统计在线人数：1.3.7 文档已把该属性标记为弃用（推荐 `game_ctrl.players`），当前版本仍可使用；
- 踢出依赖机器人具有管理员权限、服务器允许 `kick` 指令。
