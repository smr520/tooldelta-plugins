# 前置_tps计算器 0.0.2
> 监听服务器时间包估算 TPS，为其它插件提供 TPS 查询接口。

## 功能
- 监听 `IDSetTime` 数据包，用「服务器时间（游戏刻）增量 ÷ 真实时间增量」计算 TPS。
- 计算结果限制在 `0~20`；首个时间包只记录基准，不参与计算。
- 使用 `time.monotonic()` 计时，避免系统时间跳变影响结果。
- 服务器时间不推进（例如关闭昼夜更替）时只提示一次 `无法正确取得租赁服 tps`，并提示开启昼夜更替。
- 只在收到 `IDSetTime` 包时更新数值，不主动向服务器查询；两次有效更新之间（40 秒内）沿用上一次结果。
- 其它插件可通过 `GetPluginAPI("tps计算器")` 调用 `get_tps()`；超过 40 秒没有有效更新时返回 `0`，表示测不到。
- 刚加载、尚未产生有效计算时，`get_tps()` 会先返回初始值 `20`，直到超过 40 秒没有更新才改为返回 `0`；无法据此区分“满速”和“数据未就绪”。
- 插件本身不发送任何游戏消息或群消息，只提供数值。
- 本目录为第三方插件的本地修改版：原作者 `SuperScript`。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| 无 | - | 不依赖其它插件 |

`datas.json` 的 `plugin-id` 为 `tpscalculator`，`群服互通` 在 `pre-plugins` 中按这个 ID 声明前置；`群服互通` 的查询/帮助信息会用它显示 TPS。

## 安装
1. 将 `前置_tps计算器/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
无配置文件，开箱即用；TPS 的更新频率完全由服务器发来的 `IDSetTime` 包决定。

## 指令
本插件无手动指令；如需在游戏或群里查看 TPS，使用依赖本插件的插件（例如 `群服互通` 的查询功能）。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库与 ToolDelta 内置模块（`constants.PacketIDS.IDSetTime`），无第三方库；
- 需要机器人能收到服务器的 `IDSetTime` 包，且服务器开启昼夜更替让世界时间持续推进，否则无法计算 TPS；
- 不依赖 `群服互通`，但 `群服互通` 会软引用它（`force=False`），未安装时其 TPS 显示会跳过；
- `get_tps()` 返回浮点数，结果已限制在 `0~20`；测不到时固定返回整数 `0`；
- 运行时 API 名与市场 ID 不同：`plugin_entry` 注册的入口 ID 是 `tps计算器`，`datas.json` 的 `plugin-id` 是 `tpscalculator`；前置声明用后者，`GetPluginAPI` 用前者。

## 版本记录
- `0.0.2`（2026-10-27，原作者 `SuperScript`）：本地修正 TPS 公式，改为「时间戳增量 ÷ 真实时间增量」（原公式会把 20 TPS 算成约 1 TPS）；结果限制 `0~20`；首包仅作基准；长时间收不到时间包仍返回 `0`。
