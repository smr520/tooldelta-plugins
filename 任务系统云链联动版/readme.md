# 任务系统云链联动版 0.0.5
> 用 JSON 定义自定义任务的云链任务系统，支持配置热载入与命令方块触发

收录自 ToolDelta 官方插件市场，原作者 SuperScript / 小六神；本仓库有标准化修改。

## 功能
- **JSON 任务定义**：每个任务一个 JSON 文件，任务标签名即 `<任务组目录>/<文件名去掉 .json>`，支持显示名、描述、需求物品、检测指令、冷却模式和完成奖励。
- **玩家任务菜单**：`.rw` / `.任务` 列出进行中的任务，输入序号即提交；`.addrw` / `.添加任务 <任务标签名>` 由 OP 选择在线玩家下发任务。
- **提交条件检测**：逐项校验 `需要的物品`（物品 ID + 数量，可带数据值）、`检测的指令`（机器人执行并判断成功）、可选的前置任务字段 `需要完成的前置任务`，以及是否只允许命令方块触发完成。
- **任务模式**：`-1` 一次性、`0` 可重复、`>0` 为完成后冷却秒数；任务完成后执行奖励指令、发放物品，并把配置的新任务继续下发给玩家。
- **配置热载入**：主配置和任务文件变更后按 `动态载入设置` 自动重载（默认每 5 秒检测一次），无需 `reload`；玩家进度保存在 `任务数据/<玩家XUID>.json`。
- **命令方块联动**：通过 `Cb2Bot通信` 注册 `quest.start`、`quest.ok` 消息，命令方块用 `tellraw @a[tag=robot]` 即可开始或完成指定玩家的任务。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `聊天栏菜单` | 0.0.1 | 注册 `.rw`、`.addrw` 等触发词 |
| `Cb2Bot通信` | 0.0.2 | 接收命令方块 tellraw 消息；已在 `datas.json` 的 `pre-plugins` 声明 |
| `ZBasic`（可选） | 0.0.1 | 可选接口，未安装时按普通任务系统运行 |

## 安装
1. 将 `任务系统云链联动版/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/任务系统云链联动版.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `动态载入设置.是否启用动态载入配置文件（仅用于本插件）` | `true` | 是否轮询配置文件与任务文件并自动重载 |
| `动态载入设置.动态载入检测时间间隔（单位：秒）` | `5` | 轮询间隔，非法或非正数回退为 5 |
| `任务设置.任务列表显示格式` | 3 条文本 | 第 1 条为标题、第 2 条为任务行（`[i]`、`[任务显示名]`、`[任务描述]`）、第 3 条为输入提示（`[任务数量]`） |
| `任务设置.接到新任务时执行的指令` | 2 条（音效 + tellraw） | 下发任务时执行，支持 `[玩家名]`、`[任务显示名]`、`[任务描述]` |
| `任务设置.任务完成执行的指令` | 2 条（tellraw + 音效） | 任务完成时执行，支持 `[玩家名]` |
| `任务设置.任务无法提交的显示.格式` | `§c任务无法达成， 原因:\n [原因]` | 提交失败提示，支持 `[玩家名]`、`[原因]` |
| `任务设置.任务无法开始的显示.格式` | `§c任务无法开始， 原因:\n [原因]` | 下发失败提示，支持 `[玩家名]`、`[原因]` |

任务文件放在 `插件数据文件/任务系统云链联动版/任务/<任务组>/<任务名>.json`，字段如下：

```json
{
  "显示名": "空岛の源初日",
  "描述": "获取10个树苗和1组圆石",
  "检测的指令": [],
  "需要的物品": {"树苗": ["sapling", 10], "圆石": ["cobblestone", 64]},
  "只能由命令方块触发完成": false,
  "任务模式(-1=一次性 0=可重复做 >0为任务冷却秒数)": -1,
  "需要完成的前置任务": ["开局任务/新手"],
  "任务完成": {
    "执行的指令": ["xp 1L [玩家名]"],
    "给予的物品": {},
    "开启的新任务": ["开局任务/刷怪"]
  }
}
```

`需要的物品` 的值可写 `[物品ID, 数量]` 或 `[物品ID, 数量, 数据值]`；`任务完成.给予的物品` 只接受 `[物品ID, 数量]` 两项。`需要完成的前置任务` 为可选字段，不是标准模板键，写错不会被配置校验拦截。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.rw`、`.任务` | 所有玩家 | 查看进行中的任务，输入序号提交 |
| 聊天栏 | `.addrw <任务标签名>`、`.添加任务 <任务标签名>` | OP | 列出在线玩家并选择下发任务 |
| 命令方块 | `tellraw @a[tag=robot]` 中依次写 `quest.start`、玩家选择器、任务标签名 | 无 | 开始任务，如 `{"rawtext":[{"text":"quest.start"},{"selector":"@p"},{"text":"开局任务/新手"}]}` |
| 命令方块 | 同上前缀改为 `quest.ok` | 无 | 为指定玩家直接提交任务 |

命令方块需设为「脉冲 + 红石控制」，激活一次执行一次；命令方块发送的内容由 `Cb2Bot通信` 解析。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 无第三方 Python 库；物品数量检测依赖机器人读取玩家背包，坐标/指令检测通过原版指令返回判断。
- 实际硬依赖 `聊天栏菜单` 与 `Cb2Bot通信`；`datas.json` 只声明了 `聊天栏菜单`，请手动确认 `Cb2Bot通信` 已安装。
- 玩家进度按 XUID 存盘，同一账号改名后进度仍保留；配置文件/任务文件热载入失败时会保留旧任务表并输出错误。
