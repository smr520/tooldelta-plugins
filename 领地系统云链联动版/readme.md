# 领地系统云链联动版 0.1.19
> 圆形/方形领地创建与防护，含成员管理、传送、禁区与外部插件 API

收录自 ToolDelta 官方插件市场，原作者 小石潭记qwq/小六神；本仓库有标准化修改。

## 功能
- **领地创建**：聊天栏输入唤醒词（默认 `.领地`）打开菜单，选择创建圆形领地（半径 1~`最大领地半径`）或方形领地（长/高/宽），中心取玩家当前坐标；坐标获取失败时可在 30 秒内手动输入 `x y z`。
- **创建限制**：每个玩家最多拥有 `最大领地数量` 个领地；与已有领地或「不可创建领地区域」重叠时拒绝创建，圆形/方形之间会做几何相交判断。
- **菜单管理**：主菜单含 创建领地、删除领地、查看领地信息、成员管理、管理员管理、传送到领地、查看领地列表、测试当前位置；菜单输入有超时，输入 `.`、`q` 或 `退出` 可退出菜单。
- **成员与权限**：领地分领主、管理员、成员三级；管理员可管理成员，成员可传送到领地；领地信息包含中心、范围、领主、管理员、成员列表。
- **自动防护**：后台按 `检测间隔` 轮询在线玩家坐标；非成员进入他人领地会被随机传送到 `传送半径` 内（最近 10 格）并收到提示；非成员靠近领地 `缓冲区距离` 内会收到警告并被切换为冒险模式。
- **传送冷却**：被防护传送的玩家 5 秒内不会再次触发，避免传送循环刷屏。
- **不可创建区域**：`不可创建领地区域.json` 支持圆形（中心+半径）和方形（起点+终点）禁区，可在控制台菜单增删；领地不能与启用的禁区重叠。
- **配置/数据热载入**：主配置与禁区文件变更后按 `动态载入设置` 自动重载（默认每 5 秒检测一次），无需 `reload`。
- **外部 API**：提供 `api_list_lands`、`api_get_land`、`api_add_land`、`api_delete_land`、`api_add_member`、`api_set_member_rank`、`api_remove_member`、`api_transfer_owner`、`api_update_land_center`、`api_update_land_range`、`api_reload_land_config`、`api_get_runtime_status` 等方法。
- **旧数据迁移**：若存在旧版 `插件数据文件/领地系统/` 下的数据文件，首次加载会复制到新目录，不覆盖已存在的新文件。

## 安装
1. 将 `领地系统云链联动版/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/领地系统云链联动版.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `动态载入设置.是否启用动态载入配置文件（仅用于本插件）` | `true` | 是否轮询配置文件并自动重载 |
| `动态载入设置.动态载入检测时间间隔（单位：秒）` | `5` | 轮询间隔，非正数回退为 5 |
| `是否启用` | `true` | 插件总开关，关闭后不响应唤醒词也不执行防护 |
| `唤醒词` | `[".领地"]` | 聊天栏直接输入这些词打开主菜单 |
| `数据文件` | `"领地数据.json"` | 领地数据文件名（位于插件数据目录） |
| `检测间隔` | `2` | 后台防护轮询间隔（秒） |
| `缓冲区距离` | `5` | 靠近领地的警告距离（格），`0` 表示不预警领地外玩家 |
| `传送半径` | `5000` | 闯入者随机传送的最远距离（最近 10 格） |
| `最大领地半径` | `200` | 圆形领地半径上限 |
| `最大领地长` / `最大领地高` / `最大领地宽` | `200` | 方形领地尺寸上限 |
| `最大领地数量` | `4` | 每个玩家可拥有的领地上限 |
| `白名单` | `[]` | 不参与防护检测的玩家名，管理员账号请按需加入 |

数据文件：
- `插件数据文件/领地系统云链联动版/领地数据.json`：按 `land_id` 保存领地名称、领主、中心、半径、形状、尺寸、维度、成员和创建时间。
- `插件数据文件/领地系统云链联动版/不可创建领地区域.json`：禁区列表，条目字段为 `名称`、`启用`、`类型`（`圆形`/`方形`），圆形用 `中心`+`半径`，方形用 `起点`+`终点`。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.领地`（`唤醒词`） | 所有玩家 | 打开领地功能菜单 |
| 聊天栏输入 | 菜单序号或文本 | 所有玩家 | 按菜单提示操作；创建需输入名称/类型/半径或长高宽 |
| 聊天栏输入 | `x y z` | 所有玩家 | 无法自动获取坐标时手动输入坐标 |
| 控制台 | `领地系统云链联动版`、`领地系统` | 控制台 | 控制台管理菜单：增删不可创建区域、增删玩家领地、管理玩家领地 |
| 控制台 | `领地云链测试 [玩家名]`、`领地测试 [玩家名]` | 控制台 | 输出指定玩家当前坐标，用于排查坐标获取 |

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 无第三方 Python 库；坐标优先用 `game_utils.getPos` 读取，失败时执行 `/data get entity <玩家> Pos` 解析返回值。
- 需要 `XUID获取` 0.0.7+；防护与传送判定目前只处理维度 0（主世界），领地记录中的 `dimension` 字段供 API 与后续扩展使用。
- 防护通过机器人执行 `tp`、`gamemode`、`tellraw` 等原版指令实现，机器人需要有对应权限。

## 说明
- 默认配置已清空 `白名单`，并把「不可创建领地区域」的主城示例改为 `启用=false`、坐标 `[0, 64, 0]`，安装后按自己服务器填写即可。
- 防护对靠近领地的非成员会执行 `/gamemode adventure`，代码不会自动恢复原游戏模式，建议配合其它插件或在维护时调整。
- 「不可创建领地区域」只在创建/编辑领地时校验，修改禁区文件后不会反向清理已存在的领地。
- 控制台管理菜单可对任意玩家领地执行成员、管理员、领主与范围变更，操作入口仅限控制台。
