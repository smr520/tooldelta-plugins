# 群服互通云链版 0.3.1
> 单群、云链 WebSocket 直连的 QQ 群 ↔ 游戏互通插件。

原作者 大庆油田 / SuperScript，`群服互通云链版/` 为本地修改版。

## 功能

- **消息互通**：链接群与游戏聊天双向转发；玩家进/退游戏在群里提示；首次连上云链后发送上线通知；按 `message_id` 去重，避免重连后重放旧消息。
- **在线查询**：`list` / `玩家列表` 查看在线玩家；安装了 `tps计算器` 时附带 TPS。
- **信息查询**：玩家坐标、计分板、物品数量（支持中文物品名）、背包查询。
- **背包图片**：`.查背包 <玩家>` 按 176×166 背包 UI 渲染 PNG（内置 466 个物品图标、1398 条物品中文名、148 条附魔名）；带页码时改发文字分页（每页 20 格）。
- **Orion 联动**：超管可用 `orban` / `orunban` 写入 / 删除 Orion 的 XUID 封禁记录，封禁前检查 Orion 白名单。
- **权限与风控**：超管 / 普通权限 / 屏蔽三级；非超管指令 1 秒限频；非超管禁止 `tp`、`teleport`、`ride`、`spreadplayers`、`op`、`deop`、`stop`（含 `execute ... run` 形式）；发送队列约 5 条/秒，长消息自动分段，断线按 5/10/20/40/60 秒退避重连。

## 安装

1. 将 `群服互通云链版/` 整个目录复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 在配置文件中填好云链地址、校验码和链接的群聊后再 `reload`；
4. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置

配置文件路径：`插件配置文件/群服互通.json`（首次加载自动生成；0.2.3～0.3.1 配置结构保持兼容）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `云链设置.地址` | `ws://127.0.0.1:3001` | 云链 WebSocket 地址（示例占位） |
| `云链设置.校验码` | 空字符串 | 作为 `Authorization: Bearer` 请求头发送；为空则不带 |
| `云链设置.心跳间隔` | 30 | 可选，代码读取，最小 5 秒；默认模板不列出该键 |
| `权限设置.超级管理员QQ号` | 0 | 主超管 QQ |
| `权限设置.额外超级管理员QQ号` | 未在默认模板 | 可选，多超管支持 |
| `权限设置.初始普通指令权限QQ号` | `[]` | 启动时并入 `插件数据文件/群服互通/qq_permissions.json` |
| `权限设置.初始屏蔽QQ号` | `[]` | 启动时并入 `插件数据文件/群服互通/blocked_qqs.json` |
| `消息转发设置.链接的群聊` | 0 | 唯一处理的群号；不大于 0 时告警且不处理群消息 |
| `消息转发设置.游戏到群.是否启用` | `true` | 游戏 → 群总开关 |
| `消息转发设置.游戏到群.转发格式` | `<[玩家名]> [消息]` | 占位符 `[玩家名]`、`[消息]` |
| `消息转发设置.游戏到群.仅转发以下符号开头的消息(列表为空则全部转发)` | `[]` | 白名单前缀 |
| `消息转发设置.游戏到群.屏蔽以下字符串开头的消息` | `[]` | 黑名单前缀，优先于白名单 |
| `消息转发设置.群到游戏.是否启用` | `true` | 群 → 游戏总开关 |
| `消息转发设置.群到游戏.转发格式` | `<[昵称]> [消息]` | 占位符 `[昵称]`、`[消息]` |
| `服务器标识配置` | `{}` | 旧配置预留键，当前代码未读取 |

私聊消息和其他群的消息会被忽略；群里的 CQ 码（图片、表情等）转发到游戏前会替换成可读文字。

## 指令

| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 控制台 | `QQ` / `发群 <消息>` | 无 | 向链接群发测试消息 |
| 群聊 | `help` / `帮助` | 所有群成员 | 帮助菜单与运行状态 |
| 群聊 | `list` / `玩家列表` | 所有群成员 | 在线玩家，附带 TPS |
| 群聊 | `/<MC指令>` | 普通权限 | 执行游戏指令，非超管受高危指令拦截 |
| 群聊 | `/查询背包 <玩家名>` | 普通权限 | 同 `.查背包`，默认发图片 |
| 群聊 | `.查坐标 <玩家名>` | 普通权限 | 维度与 X / Y / Z |
| 群聊 | `.查计分板 <玩家名> <计分板名>` | 普通权限 | 查询计分板分数 |
| 群聊 | `.查物品数量 <玩家名> <物品名/ID>` | 普通权限 | 支持中文名，如 `.查物品数量 玩家名 泥土` |
| 群聊 | `.查背包 <玩家名> [页码]` | 普通权限 | 无页码发图片；带页码发文字版（20 格/页），支持带空格玩家名 |
| 群聊 | `orban` / `猎户封禁 <玩家名/XUID> <时长> [原因]` | 超管 | 时长由 Orion 解析：`7日`、`12时`、`30分` 等可组合，`-1` 为永久 |
| 群聊 | `orunban` / `猎户解封 <玩家名/XUID>` | 超管 | 删除 Orion 的 XUID 封禁记录 |
| 群聊 | `.添加权限QQ` / `.移除权限QQ <QQ号>` | 超管 | 维护普通指令权限名单 |
| 群聊 | `.屏蔽玩家` / `.取消屏蔽玩家 <QQ号>` | 超管 | 维护屏蔽名单 |
| 群聊 | `.查看权限列表` | 超管 | 查看超管、普通权限、屏蔽名单 |
| 群聊 | `.诊断` / `.状态` / `.stats` | 超管 | 版本、连接、队列、素材与统计信息 |

权限说明：超管 = `超级管理员QQ号` + 额外超管；普通权限 = 超管 + 初始 / 运行时添加的 QQ；被屏蔽 QQ 无法使用任何指令，消息也不会转发到游戏；非超管每条指令至少间隔 1 秒。

## 消息互通与对外接口

- `群服互通/数据json`：把原始云链消息广播给其它插件，任一监听者返回非空即视为接管该消息。
- `群服互通/链接群消息`：广播 `{"QQ号": int, "昵称": str, "消息": 原始消息}`，同样可被其它插件接管。
- `add_trigger(...)`：供其它插件注册群指令，兼容 3 参回调 `(QQ号, 参数列表, 消息类型)`，回调返回非空字符串会自动回复到群。
- 公开属性 / 方法：`sendmsg(group_id, message, split=True)`、`_send_group(message)`、`ws`、`ws_connected`、`linked_group`。

## 依赖与兼容

- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- `websocket` 由 ToolDelta 自带依赖 `websocket-client` 提供，无需用户另装。
- 云链端需支持 `send_group_msg` 与 `[CQ:image,file=base64://…]`；不支持图片时群友只能看到文字版说明。
- 背包图片只用标准库 `zlib` / `struct` 拼图和编码 PNG，不依赖 Pillow，也不依赖 `pip模块支持`。
- 物品中文名可用 `插件数据文件/群服互通/items.json` 覆盖内置名称表。
- 与官方市场的 `群服互通云链版Ultra版` 是不同实现，同一实例只应启用其中一个，避免抢同一个云链。
