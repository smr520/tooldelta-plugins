# 无邪玩家互传 1.0.0
> 支持拼音模糊搜索与双向传送请求的玩家互传插件，带冷却和接收偏好

原作者 无邪，本目录为本地修改版。

## 功能
- **双向传送请求**：`.tpa to <玩家>` 请求传送到目标玩家，`.tpa here <玩家>` 请求目标玩家传送到自己；被请求方用 `.tpa accept` 同意或 `.tpa deny` 拒绝，发起方可用 `.tpa cancel` 取消。
- **请求生命周期管理**：每个玩家同一时间只能有一条自己发出的待处理请求（仍可同时收到多名玩家的请求）；请求默认 60 秒超时，超时后通知双方并自动删除；玩家下线时自动取消其相关请求；`.tpa list` 可查看自己发送/收到的请求与剩余时间。
- **拼音 / 模糊搜索**：安装 `pypinyin` 后支持全拼和拼音首字母（如 `zhang`、`zs` 均可匹配“张三”），并对玩家拼音与首字母做缓存；未安装时只按英文/数字名称匹配。搜索结果最多返回 10 条。
- **玩家选择菜单**：`.tpa` 无参数时列出在线玩家并按序号选择输入，输入 `q` 退出；`.tpa <玩家名>` 为快捷请求传送到该玩家。
- **冷却与接收偏好**：普通玩家发起请求受冷却时间限制（默认 5 秒），OP 不受冷却限制；`.tpa toggle` 可关闭/开启接收他人的传送请求。
- **机器人排除**：在线玩家列表与搜索结果会自动排除机器人自身，避免把机器人当作传送目标。

## 安装
1. 将 `无邪玩家互传/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/无邪玩家互传.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `传送超时时间` | `60` | 传送请求有效期（秒） |
| `冷却时间` | `5` | 发起请求后的冷却时间（秒），OP 不受限制 |
| `触发命令` | `["tpa","tp","传送"]` | 注册到聊天栏菜单的触发词，实际输入形如 `.tpa` |
| `消息配置` | 11 条默认提示 | 菜单标题、请求已发送、冷却中、玩家不存在等文本，支持 `{target}`、`{sender}`、`{time}`、`{player}` 占位符 |
| `最大传送距离` | `0` | 当前代码未读取，未生效 |
| `是否允许跨维度传送` | `false` | 当前代码未读取，未生效 |
| `权限设置` | `{"所有玩家都可使用": true, "OP专用功能": ["强制传送","无冷却传送"]}` | 当前代码未读取，未生效 |

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.tpa`、`.tpa help`、`.tpa 帮助` | 所有玩家 | 显示帮助菜单 |
| 聊天栏 | `.tpa to <玩家名>`、`.tpa 去 <玩家名>` | 所有玩家 | 请求传送到目标玩家 |
| 聊天栏 | `.tpa here <玩家名>`、`.tpa 来 <玩家名>` | 所有玩家 | 请求目标玩家传送到自己 |
| 聊天栏 | `.tpa accept`、`.tpa 同意`、`.tpa acc` | 所有玩家 | 同意发给自己的请求 |
| 聊天栏 | `.tpa deny`、`.tpa 拒绝`、`.tpa dec` | 所有玩家 | 拒绝发给自己的请求 |
| 聊天栏 | `.tpa cancel`、`.tpa 取消` | 所有玩家 | 取消自己发出的请求 |
| 聊天栏 | `.tpa list`、`.tpa 列表` | 所有玩家 | 查看待处理请求与剩余时间 |
| 聊天栏 | `.tpa toggle`、`.tpa 设置` | 所有玩家 | 切换是否接收传送请求 |
| 聊天栏 | `.tpa info`、`.tpa 信息` | 所有玩家 | 查看插件信息，OP 额外显示冷却中/关闭接收人数 |
| 聊天栏 | `.tpa <玩家名>` | 所有玩家 | 快捷请求传送到该玩家，支持模糊搜索 |
| 聊天栏输入 | 序号 或 `q` | - | 在选择菜单中选人/退出，30 秒无输入视为超时 |

触发词由 `触发命令` 决定，默认 `.tpa`、`.tp`、`.传送` 三种写法等价。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 第三方库 `pypinyin`（可选）：优先直接 `import`，失败时通过 `pip` 前置的 `require()` 安装；仍失败则拼音搜索关闭，仅保留英文/数字匹配。
- 传送通过机器人执行 `tp` 指令并用返回的 `SuccessCount` 判断成功；请求列表与接收偏好只保存在内存，`reload` 或重启后清空。

## 版本记录
- `1.0.0`：为玩家拼音与首字母增加缓存，减少重复转换；预加载阶段不再调用 `say_to`，避免游戏尚未连接时报错；补充异常处理与兼容调整。

## 说明
- 拼音搜索依赖 `pypinyin`，未安装时帮助菜单会提示“拼音搜索需要安装 pypinyin 库”。
- 配置中的 `最大传送距离`、`是否允许跨维度传送`、`权限设置` 目前只生成配置模板、代码未使用，请勿据此判断实际行为。
- 传送请求超时与冷却时间均可在配置中调整；机器人自身不会出现在可传送目标中。
