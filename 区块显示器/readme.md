# 区块显示器 0.0.3
> 在聊天栏查看当前区块范围与地图画区域起点。

> 收录自 ToolDelta 官方插件市场，原作者 `SnowLotus`；本仓库有标准化修改。

## 功能
- 聊天栏触发词 `显示区块` / `区块范围`：读取玩家当前坐标，按 8 取整算出所在「区块」的起始点与终止点（终止点 = 起始点 + 7）。
- 聊天栏触发词 `地图画起点`：按 128 取整算出当前所在地图画区域的起始点（只显示起点，不显示终点）。
- 结果只通过 `player.show()` 私聊给触发玩家，不广播、不修改世界、不发送游戏指令。
- 只使用坐标的 X / Z 分量（`int(x // 8) * 8`、`int(x // 128) * 128`），Y 坐标不参与计算。
- 注意：本插件的「区块」按 8×8 计算，与原版 16×16 区块不同；「地图画区域」按 128×128 计算。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `聊天栏菜单` | 0.0.1 | 注册聊天栏触发词（本仓库对应目录 `前置_聊天栏菜单`，收录版本 0.4.1） |

## 安装
1. 将 `区块显示器/` 复制到实例的 `插件文件/ToolDelta类式插件/`，同时安装前置 `前置_聊天栏菜单/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
无配置文件，开箱即用。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `显示区块` 或 `区块范围` | 无 | 显示当前区块起始点 `(x, z)` 与终止点 `(x+7, z+7)` |
| 聊天栏 | `地图画起点` | 无 | 显示当前地图画区域起始点 `(x, z)` |

触发时可能带聊天栏菜单配置的前缀（默认 `.`、`。`、`·`）；本插件没有控制台或群聊指令。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库与 `tooldelta.game_utils.getPosXYZ`，无第三方库；
- 玩家坐标读取依赖框架提供的 `getPosXYZ`，本插件不自行轮询坐标；
- 通过 `GetPluginAPI("聊天栏菜单")` 取得前置实例，`datas.json` 声明的 `pre-plugins` 为 `聊天栏菜单 >= 0.0.1`。
