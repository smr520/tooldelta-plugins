# 崩溃提醒 0.0.1
> 检测到机器人进程崩溃日志时，立即通过群服互通向绑定群发送提醒。

## 功能
- 在根日志上挂载处理器，只监听 `WARNING` 及以上级别的日志；处理器在插件构造时挂载，框架退出时移除。
- 日志去掉 ANSI 颜色码后按小写做子串匹配，命中以下任一关键词才触发（不区分大小写）：`conn dead`、`FateArk 已崩溃`、`启动器框架崩溃`、`接入点进程已崩溃`、`MemoryError`、`FateArk掉线`。
- 命中后直接使用 `群服互通` 当前的 WebSocket 发送群消息，不经过消息队列，避免进程退出时消息丢失。
- 发送放在守护线程中进行，最多等待 1.5 秒让消息发出，然后继续进程退出流程。
- 30 秒内只发送一次，避免同一次崩溃重复刷屏。
- 消息内容固定为 `⚠️ 机器人进程崩溃，游戏服务器不受影响。`，群号取 `群服互通` 当前绑定的群聊。
- 不改游戏服、不写配置、不打包日志；本插件为自建插件（作者 `一个高质量的神秘人`）。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `群服互通` | 未校验 | 提供 WebSocket 连接、绑定群号与发送锁 |

说明：`datas.json` 的 `pre-plugins` 为空，本插件用 `GetPluginAPI("群服互通", force=False)` 软获取；未安装时只打印提示，不中断插件加载。

## 安装
1. 将 `崩溃提醒/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 确保 `群服互通` 已安装并连上云链、配置好绑定群；
3. 启动实例，或在 ToolDelta 控制台执行 `reload`；
4. 也可以把本仓库添加为自定义插件市场源后直接安装。

正常日志为 `崩溃提醒已启用：监听机器人进程崩溃日志`；若出现 `暂未找到 群服互通`，需要先检查前置插件。

## 配置
无配置文件，开箱即用。群号与云链连接沿用 `群服互通` 的配置。

## 指令
本插件无手动指令。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库（`json`、`logging`、`re`、`threading`、`time`），无第三方库；
- 发送时读取 `群服互通` 的 `ws`、`ws_connected`、`_send_lock`、`linked_group`，属于该插件的内部实现，`群服互通` 升级后可能失效；
- 限制：进程被瞬间杀死（如 OOM、强制结束）、崩溃日志尚未产生、或云链已断开时，插件没有机会发送；需要完整覆盖时应在面板外另加 watchdog。

## 版本记录
- `0.0.1`（2026-10-28）：新增自建插件；监听崩溃关键词后通过 `群服互通` WebSocket 直发提醒，不走发送队列、最多等 1.5 秒、30 秒冷却；不打包、不存日志、不改配置、不做启动补发。
