# 前置_统一消息风格 0.0.3
> 为其它插件统一玩家消息的样式，并提供带分页的选择菜单。

收录自 ToolDelta 官方插件市场，原作者 `ToolDelta`；本仓库有标准化修改。

## 功能
- 通过 `plugin_entry` 注册 API 名 `统一消息风格`，其它插件用 `GetPluginAPI("统一消息风格")` 取得实例；`datas.json` 的 `plugin-id` 同为 `统一消息风格`。
- 提供 `info` / `success` / `warn` / `failed` / `error` 五类消息：把配置模板中的 `[消息]` 替换为文本后，用 `player.show()` 发给玩家。
- `input(player, text)`：把 `[消息]` 替换进「输入提示」模板，再调用 `player.input()` 读取并返回玩家输入。
- `select(player, prompt, arguments, sections_formatter)`：按「单页最多项数」分页显示「序号 + 内容」，读取玩家输入后返回对应对象；输入 `+` / `-` 翻页；无效输入提示 `请输入 1~N 中的一个序号：`；玩家取消时返回 `None`。
- `select_meta(...)` 在 `select` 的基础上追加一组字符串型额外选项（例如「取消」），输入命中时原样返回该字符串。
- `__call__(player)` 返回 `StyledPlayerPrinter` 包装对象，可省略 player 参数调用：`api(player).success("...")`，等价于 `api.success(player, "...")`。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| 无 | - | 不依赖其它插件 |

本插件自身是给其它插件调用的 API 前置；其它插件未安装它时，`GetPluginAPI("统一消息风格", force=False)` 返回 `None`，需要调用方自行降级。

## 安装
1. 将 `前置_统一消息风格/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/统一消息风格.json`（首次加载自动生成；配置名取类内 `name`，不带目录前缀 `前置_`）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `普通消息` | `§7[§fi§7] §f[消息]` | `info()` 使用的模板 |
| `成功消息` | `§7[§a√§7] §a[消息]` | `success()` 使用的模板 |
| `警告消息` | `§7[§6!§7] §6[消息]` | `warn()` 使用的模板 |
| `失败消息` | `§7[§cx§7] §c[消息]` | `failed()` 使用的模板 |
| `报错消息` | `§7[§4E§7] §c[消息]` | `error()` 使用的模板 |
| `输入提示` | `§7[§f!§7] §f[消息]` | `input()` 使用的模板 |
| `选择格式.选择头` | `§6[选择提示] §7>>>` | 选择菜单标题，`[选择提示]` 由调用方传入 |
| `选择格式.选项` | `  [序号]. [内容]` | 单个候选项的显示格式 |
| `选择格式.选择尾` | `§7请输入 §f1~[最大序号] 中的一个序号以选择：` | 单页选择提示 |
| `选择格式.选择尾(多页)` | `§7请输入 §f1~[最大序号] 中的一个序号以选择 输入 §a+§7/§6-§7 进行翻页：` | 候选超过一页时的提示（`select_meta` 使用） |
| `选择格式.向后翻页命令` | `+` | 下一页输入 |
| `选择格式.向前翻页命令` | `-` | 上一页输入 |
| `选择格式.单页最多项数` | `10` | 每页候选数；小于 `2` 时插件加载抛 `cfg.ConfigError` |
| `选择格式.额外选项格式(如果存在额外选项)` | `或[额外选项提示]：` | `select_meta` 额外选项的提示行 |

模板中的 `[消息]`、`[选择提示]`、`[序号]`、`[内容]`、`[最大序号]`、`[额外选项提示]` 由代码替换；删掉占位符会导致对应内容不显示。

## 指令
本插件无手动指令；选择菜单通过读取玩家聊天栏输入（`player.input()`）工作，不注册控制台或聊天栏指令。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 仅使用标准库与 ToolDelta 内置模块（`tooldelta.Player`、`tooldelta.cfg`、`tooldelta.utils`），无第三方库。
- 消息模板使用 Minecraft 颜色代码 `§`；显示与输入依赖玩家聊天栏可用。
- 候选对象由调用方的 `sections_formatter` 转成文本，插件本身不关心对象类型。
