# 前置_大字替换 0.0.2

> 把 ASCII 数字和字母替换为全角大字字符的前置 API。

> 收录自 ToolDelta 官方插件市场，原作者 ToolDelta；本仓库仅做文件名/文档规范统一，未改动插件功能代码。

## 功能

- 提供 `replaceBig` 方法，把字符串中的 ASCII 数字、小写字母和大写字母替换为对应的全角字符（如 `A1` → `Ａ１`）。
- 基于 `utils.simple_fmt` 做逐字符映射，其余字符（中文、标点、空格、颜色代码等）原样保留。
- 方法为类内静态方法，通过插件实例调用即可。
- 纯前置 API，安装后不会主动产生游戏内效果。

## 前置插件

无。

## 安装

1. 将 `前置_大字替换/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置

无配置文件，开箱即用。

## API

在其它插件的 `on_preload` 中获取本插件实例：

```python
api = self.GetPluginAPI("大字替换")
print(api.replaceBig("Hello 123"))
# 输出：Ｈｅｌｌｏ １２３
```

| 方法 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `replaceBig` | `t: str`：待替换的文本 | `str`：替换后的文本 | 把 `0-9`、`a-z`、`A-Z` 替换为全角字符，其余字符不变。 |

- 映射范围只包含数字与英文字母，空格、`§` 颜色代码、中文等不会改变。
- 映射表由插件内置，不支持外部自定义。

## 指令

本插件无手动指令。

## 依赖与兼容

- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）
- 无第三方库依赖
- 依赖 ToolDelta 自带的 `tooldelta.utils.simple_fmt`

## 说明

- 本插件是纯前置 API，单独安装没有可见效果；需要大字效果的插件应先通过 `self.GetPluginAPI("大字替换")` 取得实例。
- 仅转换单字节 ASCII 字母和数字，不做其它字符的排版或格式化。
