# 前置_聊天栏菜单 0.4.1
> 聊天栏触发词菜单前置：注册指令、校验参数、生成帮助与序号菜单。

## 功能
- 用 `add_new_trigger()` 注册聊天栏触发词，支持多个触发词、参数类型（`str` / `int` / `float` / `bool`）、默认值和「限值组」。
- 玩家参数不合法时直接把错误发到聊天栏；参数不够时会逐项询问（每项最多等 240 秒，回答 `？` / `?` 用默认值）。
- 触发词前可带配置里定义的前缀，默认 `.`、`。`、`·`，也可以配置成无前缀。
- `help` 菜单支持两种样式：分页帮助（列出触发词、参数提示、功能说明）和指令序号式菜单（按序号选择、翻页、退出），由配置开关切换。
- 支持 `op_only` 注册项，非 OP 触发时提示无权限。
- 保留旧式 `add_trigger()` 接口（回调收到玩家名与字符串参数列表）。
- 菜单头/列表/尾、权限标记、配色、参数提示等样式都可配置，旧版本配置会自动补齐。
- 本目录为第三方插件的本地修改版：原作者 `SuperScript`（类内 `author` 为 `SuperScript/猫猫`）。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| 无 | - | 不依赖其它插件；其它插件反过来依赖它来注册聊天栏菜单 |

## 安装
1. 将 `前置_聊天栏菜单/` 复制到实例的 `插件文件/ToolDelta类式插件/`，`config_getter.py` 要一起保留（`__init__.py` 会 import 它）；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件：`插件配置文件/聊天栏菜单新版.json`（类内插件名是「聊天栏菜单新版」，文件名与市场 ID 不同；首次加载自动生成，旧版本配置会自动升级）。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `"/help触发词"` | `["help"]` | 打开帮助 / 菜单的触发词（配置键名带开头的 `/`） |
| `被识别为触发词的前缀(不填则为无命令前缀)` | `[".", "。", "·"]` | 聊天前缀；空列表表示直接以触发词开头 |
| `是否启用指令序号式菜单样式` | `true` | `true` 打开序号选择菜单，`false` 显示分页帮助 |
| `单页内最多显示数` | `6` | 每页显示的菜单项数量 |
| `help菜单样式` | 见默认配置 | 分页帮助的菜单头/列表/尾、管理/创造/成员标记、指令分隔符与配色、参数提示格式 |
| `指令序号式菜单样式` | 见默认配置 | 序号菜单样式，另含 `菜单退出提示` |

- 样式文本占位符：`[是否为管理员]`、`[是否为创造]`、`[是否为成员]`、`[菜单指令]`、`[参数提示]`、`[菜单功能说明]`、`[当前页数]`、`[总页数]`、`[序号]`，按 `utils.simple_fmt` 方式替换。
- 旧配置版本低于 `0.3.2` / `0.3.4` 时会自动补上新增的样式项并写回文件。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.help [页数]`（触发词可配置） | 无 | 序号菜单开启时打开序号菜单；关闭时显示分页帮助 |
| 聊天栏 | 序号、`+` / `-` | 无 | 序号菜单里选择菜单项、翻页 |
| 聊天栏 | `q` / `退出` | 无 | 退出序号菜单 |
| 聊天栏 | 各插件注册的触发词 | 视注册项 | 带前缀输入后执行对应菜单项 |

控制台没有本插件自己的指令。

## API
先 `chatbar = self.GetPluginAPI("聊天栏菜单")`（注册的 API 名有 `聊天栏菜单` 和 `chatbarmenu` 两个）。

### `add_new_trigger(triggers, argument_hint, usage, func, op_only=False)`
| 参数 | 类型 | 说明 |
|---|---|---|
| `triggers` | `list[str]` | 触发词列表，如 `["buy", "购买"]`；开头的 `.` 会被自动去掉 |
| `argument_hint` | `list[tuple]` 或 `...` | 参数提示；每个元组为 `(提示词, 参数类型, 默认值)`，默认值 `None` 表示必填；传 `...` 表示任意个字符串参数 |
| `usage` | `str` | 菜单里显示的功能说明 |
| `func` | `Callable[[Player, tuple], Any]` | 触发回调，收到玩家对象和解析后的参数元组 |
| `op_only` | `bool` | 是否仅 OP 可用，默认 `False` |

参数类型支持 `str` / `int` / `float` / `bool`，也可以写成元组表示「只能取这些值」；`bool` 参数用 `是` / `否` 输入。有默认值的参数之后不能再出现必填参数。

```python
def on_buy_test(player: Player, args: tuple):
    print(player.name, args)

chatbar.add_new_trigger(
    ["buy", "购买"],
    [("物品名", str, None), ("数量", int, 1)],
    "购买物品",
    on_buy_test,
)

# .buy apple 3   -> args = ("apple", 3)
# .buy apple     -> args = ("apple", 1)
# .buy           -> 逐项询问物品名（必填参数）
# .buy banana foo -> 玩家收到「foo 不是一个整数」
```

### `add_trigger(triggers, argument_hint, usage, func, args_pd=..., op_only=False)`（旧式，已标记废弃）
- `argument_hint` 是字符串提示或 `None`；`func(playername: str, args: list[str])` 收到玩家名和原始参数列表；
- `args_pd` 可传参数个数校验函数 `(int) -> bool`，默认恒为 `True`；
- 旧式注册项只能直接输入触发词触发，不会出现在序号菜单里（分页帮助仍会列出，但没有参数提示）；新插件建议用 `add_new_trigger()`。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库与 ToolDelta 内置模块，无第三方库；
- 本仓库内使用它的插件：`『Orion System』违规与作弊行为综合反制系统`（`pre-plugins` 声明 `聊天栏菜单 >= 0.3.2`）、`无邪玩家互传`（`>= 0.4.0`），两者都用 `add_new_trigger()` 注册菜单项；
- `datas.json` 的 `plugin-id` 是 `聊天栏菜单`；配置文件按类内插件名生成，因此是 `聊天栏菜单新版.json`；
- 触发词执行时使用 `utils.ChatbarLock(玩家名)` 串行化，避免同一玩家同时执行多个菜单项。
