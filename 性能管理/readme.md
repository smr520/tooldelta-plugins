# 性能管理 0.0.5
> 控制台查看 CPU、内存、缓存与线程，内存超限时自动停机。

收录自 ToolDelta 官方插件市场，原作者 `SuperScript`；本仓库有标准化修改。

## 功能
- 插件加载后立即检查一次内存，之后每 60 秒检查一次；占用超过告警阈值时在控制台打印内存告急信息（占用继续升高会再次提示，回落到阈值以下后重置），超过停机阈值时打印错误并以「性能管理系统强制关机」退出 ToolDelta（`system_exit()` 后 `os._exit(0)`）。
- 控制台 `性能` / `top` 指令实时显示内存（可用 / 空闲 / 总量、占用百分比）与 CPU 使用率。
- `top 1` 列出 JSON 缓存区正在缓存的文件；`top 2` 列出 ToolDelta 中运行的正常线程；`top 3` 列出定时任务表；不带参数时打印 `top` 帮助。
- 若同时加载了「更好的公告栏」插件，会向它注册 `[RAM]` 格式，把已用内存格式化为 `B` / `KB` / `MB` 后显示在公告栏。
- `psutil` 改为延迟加载：先尝试 `import psutil`，失败时通过 `pip模块支持`（`GetPluginAPI("pip")`）的 `require({"psutil": "psutil"})` 自动安装，再导入。
- 插件不写业务数据文件，只读取自己的配置。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `pip` | 0.0.5 | 加载时自动安装第三方库 `psutil`；环境里已有 psutil 时不会触发安装 |

`datas.json` 的 `plugin-id` 是 `prof_manager`。本仓库的 `pip` 前置即 `pip模块支持/`（`plugin-id` = `pip`，版本 `0.0.6`）。缺少 `pip` 且环境中没有 `psutil` 时，插件加载失败。

## 安装
1. 将 `性能管理/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；首次加载若缺少 `psutil` 会自动安装（需要可用的 pip 与网络）；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/性能管理.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `当内存占用超过多少百分比时提示警告` | `80` | 内存占用超过该百分比时在控制台告警；回落到阈值以下后可再次触发（整数百分比） |
| `当内存占用超过多少百分比时停机` | `95` | 内存占用超过该百分比时打印错误并强制退出 ToolDelta（整数百分比） |

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 控制台 | `性能` / `top [参数]` | 无 | 查看 CPU、内存；`top 1` JSON 缓存，`top 2` 线程列表，`top 3` 定时任务 |

不带参数时打印 `top` 帮助（`top 0` ~ `top 3` 的说明）；`top 0` 只输出基础的内存与 CPU 信息。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 第三方库 `psutil`：本仓库不再在顶层 `import psutil`，改为加载时通过 `pip模块支持` 自动安装；首次加载需要联网与可用的 pip 源。
- 内存阈值按整数百分比填写（0~100），代码用 `psutil.virtual_memory().percent` 与阈值直接比较；停机使用 `os._exit(0)` 强制结束进程，不会保存数据或卸载其它插件，阈值请谨慎设置。
- 「更好的公告栏」是可选软依赖（`force=False`），未安装时跳过 `[RAM]` 格式注册。
