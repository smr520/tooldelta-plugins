# 控制台一键更新插件 0.0.1
> 在 ToolDelta 控制台输入 `up`，一键更新全部已安装插件并可选立即重载。

收录自 ToolDelta 官方插件市场，原作者 `ToolDelta`；本仓库有标准化修改。

## 功能
- 插件加载时（`ListenPreload`）在 ToolDelta 控制台注册 `up` 指令，用途说明为「一键更新所有插件」。
- 执行 `up` 时先打印「正在获取更新列表..」，再调用 `plugin_manager.update_all_plugins(plugin_manager.get_all_plugin_datas())`，按当前插件市场源检查并更新全部已安装插件。
- 更新结束后在控制台询问「是否立即重载 (y/n)? 请输入:」；输入 `y` 时在系统线程（`ToolDeltaThread.SYSTEM`）中执行 `self.frame.reload()`，重载插件系统让更新生效。
- 输入其它内容（含直接回车、大写 `Y`）时不重载，只提示「可以在稍后重载系统以使更新的插件生效。」。
- 更新过程只在控制台输出日志，不向游戏或群发送消息。
- 插件不常驻后台任务，也不保存状态；所有动作都由一次 `up` 触发。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| 无 | - | 不依赖其它插件 |

`datas.json` 的 `plugin-id` 是 `fast-upgrade-plugins`。

## 安装
1. 将 `控制台一键更新插件/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
无配置文件，开箱即用。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 控制台 | `up` | 无 | 检查并更新全部已安装插件，随后询问是否立即重载 |

指令不需要参数；重载确认只把输入去掉首尾空白后与 `y` 比较，输入其它内容后需要重新执行 `up` 或手动 `reload` 才能让更新生效。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 使用 ToolDelta 内部模块 `tooldelta.plugin_manager.plugin_manager`，以及 `tooldelta.utils` 的 `fmts` / `thread_func` / `ToolDeltaThread`；升级框架后需要回归。
- 更新来源是实例当前配置的插件市场源，需要能联网；市场源不可用时由框架的更新逻辑处理，插件本身不额外捕获异常。
- 重载是整体 `frame.reload()`，会中断当前正在执行的其它任务；建议在空闲时执行。
