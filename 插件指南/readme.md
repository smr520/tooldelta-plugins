# 插件指南 1.0.0
> 在游戏内查看本服插件怎么用，解决「不知道有哪些插件、不知道怎么用」的问题。

## 功能
- 聊天栏菜单项 `.指南` / `.插件`（会出现在 `.help` 菜单里），共 3 页：
  - 第 1 页「玩家菜单」：自动列出聊天栏菜单里已注册的所有玩家可用命令与功能说明；
  - 第 2 页「自动运行」：列出无需命令、自动工作的插件（掉落物清理、崩溃提醒、进服验证、人数限制、入服欢迎、活力API 等）；
  - 第 3 页「控制台 / QQ」：控制台指令速查（性能、top、up、pip-install、d/、白名单、发群 等）与 QQ 群 `help` 提示。
- 第 1 页是动态读取 `聊天栏菜单` 的注册表，后续新装插件只要注册了菜单项就会自动出现在指南里。
- OP 专用菜单项只对管理员可见。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `聊天栏菜单` | 0.4.0 | 注册 `.指南` 菜单项，并读取其中的菜单注册表生成第 1 页 |

## 安装
1. 将 `插件指南/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
无配置文件，开箱即用。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 聊天栏 | `.指南 [页数]` | 所有玩家 | 查看插件说明，默认第 1 页 |
| 聊天栏 | `.插件 [页数]` | 所有玩家 | 与 `.指南` 相同 |

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 仅使用 ToolDelta 内置 API，无第三方 Python 库。
- 第 1 页内容取决于已安装插件注册到 `聊天栏菜单` 的菜单项；未安装 `聊天栏菜单` 时插件只打印提示、不注册菜单。

## 版本记录
