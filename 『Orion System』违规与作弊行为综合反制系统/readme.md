# 『Orion System』违规与作弊行为综合反制系统 0.4.4
> 集进服反制、发言管控、封禁解封与权限管理于一体的综合反作弊系统

原作者 style_天枢『猎户座』，本目录为本地修改版。

## 功能
- **封禁 / 解封**：提供控制台和游戏内两套分页面板，支持按在线玩家 XUID/名称、历史玩家 XUID/名称、历史设备号封禁与解封；封禁时长支持永久、指定秒数和 `X年X月X日X时X分X秒` 格式，封禁数据先落盘再踢出，到期或损坏的记录会自动清理。
- **进服反制**：机器人 IP 外进（皮肤认证字段异常）、锁服（皮肤数据 base64 尺寸校验）、Steve/Alex 皮肤、4D 皮肤、账号等级低于准入等级、名称长度/非法字符/网易屏蔽词/自定义违禁词、网易 MC 客户端信息一致性检查（可用于识别篡改等级）。
- **发言管控**：拦截游戏内私聊 `tell`/`msg`/`w` 与 `me` 命令；黑名单词检测（先清洗空格、`§` 颜色符和标点再匹配）、周期内发言频率、单条字数、重复消息刷屏、睡觉消息刷屏限制。
- **记录与自动封禁**：玩家进服时记录 XUID、设备号和历史名称；设备号先解析 `SkinID` 快速获取，失败时把机器人短时传送到玩家上方刷新 `AddPlayer` 慢速获取；违规可自动按 XUID 和/或设备号封禁并联动。
- **封禁记分板 API**：启用后通过 `Ban_System` 记分板接入封禁系统，分数为封禁秒数，`-1` 永久、`0` 仅踢出；执行后自动清零，可由命令方块或游戏内指令触发。
- **权限管理**：玩家进服自动套用能力权限组（放置、采集、门/开关、容器、攻击玩家/生物、操作员命令、传送的组合），也可通过 `Permission` 记分板分数切换权限组，例如自动设为访客。

## 安装
1. 将 `『Orion System』违规与作弊行为综合反制系统/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 控制台 | `ban`、`封禁` | 无 | 打开封禁面板：1 在线玩家；2 历史玩家 XUID/名称；3 历史设备号 |
| 控制台 | `unban`、`解封` | 无 | 打开解封面板：1 XUID/名称；2 设备号 |
| 聊天栏 | `.ban`、`.封禁` | OP 或配置允许名单 | 游戏内封禁面板，通过 `聊天栏菜单` 注册 |
| 聊天栏 | `.unban`、`.解封` | OP 或配置允许名单 | 游戏内解封面板 |
| 命令 / 命令方块 | `scoreboard players set <玩家> Ban_System <秒>` | 需开启记分板 API | `-1` 永久、`0` 仅踢出，处理完自动清零 |
| 面板输入 | `.` 或 `。`；`-` / `+` / `N页` | - | 退出面板、翻页；输入序号选择，输入名称/设备号搜索 |

游戏内封禁/解封权限由 `--操作员可使用游戏内封禁/解封系统` 和 `--以下用户无需操作员权限也可使用游戏内封禁/解封系统` 控制。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板），依赖 `PlayerList`、`Text` 数据包监听。
- `regex`：通过 `pip` 前置安装；缺失时自动回退标准库 `re` 并适配 `\p{Han}`。
- `requests`：代码直接 `import requests`，属于 ToolDelta 自带依赖；网易 MC 客户端信息检查调用公开外部接口，请确认实例能访问外网。
- 对外以 `Orion_System` 为 API 名，可供 `群服互通云链版` 等插件联动群内封禁/解封。
- 禁止私聊检测需机器人不在游戏内且开启 `/gamerule sendcommandfeedback true`，否则可能漏检。

## 版本记录
- `0.4.4`：恢复设备号两层获取（`SkinID` 解析 + 机器人传送刷新 `AddPlayer`），新增 `device_id_core.py`；封禁数据先落盘再踢出；减少回调线程、缓存正则/白名单、黑名单词改为子串匹配；发言路径 OP 检查改为非阻塞，修复封禁原因输入超时被误判为默认原因。
- `0.4.4`：配置项新增名称长度与非法名称检测；`regex` 不可用时自动回退标准库 `re`。

## 说明
- 封禁时长按 1 月 = 30 日、1 年 = 360 日换算，不考虑闰年与时区变化。
- 配置缺少新版本键或类型不符时，插件会删除并重建配置文件，修改前请备份 `插件配置文件/`。
- 配置中的 `反制白名单` 等默认值仅作示例，部署前请替换为实际管理员名单；反制触发词若与其他封禁插件重复，游戏内面板可能无法打开。
