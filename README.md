# ToolDelta 插件库

个人维护的 [ToolDelta](https://github.com/ToolDelta-Basic/ToolDelta) 类式插件集合，同时可以直接作为 ToolDelta 的**自定义插件市场源**使用。

仓库结构遵循 ToolDelta 官方插件市场（[PluginMarket](https://github.com/ToolDelta-Basic/PluginMarket)）的规范：根目录下每个中文目录就是一个插件，插件目录内包含 `__init__.py`、`datas.json` 和 `readme.md`。

## 统一改造说明

本仓库所有插件都按 [ToolDelta 1.3.7 插件开发指南](https://wiki.tooldelta.top/plugin-dev/) 做了统一整理：

- 每个插件：`__init__.py` + `datas.json` + 小写 `readme.md`；`datas.json` 的 `pre-plugins` 与代码里的 `GetPluginAPI` 对齐，缺失前置可由插件市场自动补齐；
- 移除已弃用接口（`make_data_path` / `format_data_path`），统一改用 `self.data_path`；
- 需要第三方 Python 库时通过 `pip模块支持` 自动安装，不要求手动 pip；
- 默认配置去私有化（不写作者服务器坐标/白名单/真实群号），未配置时给出明确提示、不误伤玩家；
- 不使用 NeOmega 接入点，只兼容 FateArk 等无 NeOmega 框架；
- 修复收录插件里影响使用的明显 Bug（内存阈值比较、踢出用 XUID、验证码冲突、重复回调、缺失常量等），逐项见 [NOTICE.md](NOTICE.md)。

## 游戏内菜单

游戏里不知道插件怎么用，先看菜单：

- 聊天栏发送 `.help` 查看所有已注册插件命令，`+` / `-` 翻页，`.help <页数>` 跳页；
- 聊天栏发送 `.指南`（或 `.插件`）查看三页说明：① 玩家菜单 ② 自动运行插件 ③ 控制台与 QQ 指令；
- 已注册进 `.help` 的常用项：签到 `.签到`、领地 `.领地`、公会、任务、无邪互传、Orion 封禁、区块显示器，以及 OP 专用的 `.性能`、`.人数`；
- 自动运行、不需要指令的插件：掉落物600上限清理、崩溃提醒、进服验证、玩家人数限制、入服欢迎、活力API；
- 控制台插件（`性能`/`top`、`up`、`pip-install`、`d/`、`白名单`、`发群` 等）在面板控制台使用，`.指南` 第 3 页有速查；
- QQ 群内发送 `help` 查看 `群服互通` 的群指令。

## 作为插件市场源使用

在实例的 `ToolDelta基本配置.json` 中把 `插件市场源` 改成：

```text
https://raw.githubusercontent.com/smr520/tooldelta-plugins/main
```

如果访问 GitHub 需要镜像（国内直连 raw 可能超时），按 ToolDelta 的镜像格式填写，例如：

```text
https://ghproxy.net/https://raw.githubusercontent.com/smr520/tooldelta-plugins/main
```

然后启动 ToolDelta，在控制台输入 `插件市场` 即可浏览和安装本仓库的插件。

## 手动安装

1. 把需要的插件目录整个复制到实例的：

   ```text
   插件文件/ToolDelta类式插件/<插件目录>/
   ```

2. 启动实例，或在控制台执行 `reload`；
3. 需要配置的插件，配置文件会生成在 `插件配置文件/` 下，首次加载后按插件 `readme.md` 修改。

## 仓库结构

```text
.
├── <插件目录>/
│   ├── __init__.py
│   ├── datas.json
│   ├── readme.md
│   └── ...（插件需要的其它文件）
├── market_tree.json        # 插件市场索引（自动生成）
├── plugin_ids_map.json     # 插件 ID → 目录名（自动生成）
├── latest_versions.json    # 各插件最新版本（自动生成）
├── directory_tree.json     # 文件树，客户端按此下载（自动生成）
└── _workflow.py            # 索引生成脚本
```

修改、增删插件后，运行：

```bash
python _workflow.py
```

即可重新生成索引文件，再提交。
