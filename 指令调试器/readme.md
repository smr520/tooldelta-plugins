# 指令调试器 0.0.2
> 在控制台发送指令并查看完整返回包，方便调试插件指令。

> 收录自 ToolDelta 官方插件市场，原作者 `SuperScript`；本仓库有标准化修改。

## 功能
- 控制台触发词 `d/<指令>`：用 `game_ctrl.sendwscmd_with_resp()` 执行指令并打印完整返回，示例 `d/testfor @a`。
- 控制台触发词 `dw/<指令>`：同上，示例 `dw/testfor @a`。
- 输出两段内容：第一行是 `指令结果返回 (<指令>) | 成功/失败 | 用时 x.xxs`，随后是 `indent=4`、中文不转义的返回包 JSON，可查看 `SuccessCount`、`OutputMessages` 等字段。
- 「成功/失败」按返回包中 `SuccessCount > 0` 判定，不表示指令本身语法一定正确。
- 等待返回超时时只打印「`指令返回获取超时`」，捕获的是 `TimeoutError`，不会让插件或框架崩溃。
- 两个触发词共用同一实现，都走 WebSocket 带返回接口；`d/` 与 `dw/` 只是入口名不同，效果一致。
- 除超时外，其它异常会打印 `执行指令失败：<错误>`，不会抛出到框架。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| 无 | - | 不依赖其它插件 |

## 安装
1. 将 `指令调试器/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
无配置文件，开箱即用。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 控制台 | `d/<指令>` | 无 | 发送指令并打印完整返回，如 `d/testfor @a` |
| 控制台 | `dw/<指令>` | 无 | 发送 WebSocket 指令并打印完整返回，如 `dw/list` |

本插件没有聊天栏或群聊指令；触发词是控制台前缀，指令原文写在 `/` 之后。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库（`time`、`json`）与 ToolDelta 内置 API，无第三方库；
- 需要 WebSocket 连接正常；`sendwscmd_with_resp()` 默认等待 30 秒，超时按上文提示处理；
- 指令以机器人的 WebSocket 身份执行，需要该身份具备执行对应指令的游戏权限。
