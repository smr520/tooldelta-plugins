# 掉落物600上限清理 1.0.1
> 三世界掉落物合计超过阈值时自动清理全部维度，只处理 item 实体。

## 功能
- 按 `检查间隔秒`（默认 5 秒）分别统计主世界、下界、末地的 `item` 实体数量（`testfor` 计数，检测上限为阈值 + 1）。
- 三个维度合计**严格大于**阈值（默认 600）时，对全部维度执行 `execute in <维度> run kill @e[type=item]` 清理掉落物。
- 只处理 `item` 实体，不清理玩家、生物、经验球、盔甲架等其它实体。
- 单个维度统计超时按“未知”处理：已知合计未超过阈值时本轮不清理、下一轮重试；已知部分已超过阈值时仍会清理。
- 统计与清理都在后台守护线程中进行，插件退出或框架退出时自动停止。
- 本插件为自建插件（作者 `一个高质量的神秘人`）。

|---|---|---|
| 无 | - | 不依赖其它插件 |

## 安装
1. 将 `掉落物600上限清理/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 启动实例，或在 ToolDelta 控制台执行 `reload`；
3. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/掉落物600上限清理.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `启用` | `true` | 设为 `false` 时不启动扫描线程，只在激活时提示未启用 |
| `数量阈值` | `600` | 三世界合计严格超过该值才清理；类型非法时按 `600`、小于 1 时按 1 处理 |
| `检查间隔秒` | `5` | 两次统计的间隔，最小 1 秒，类型非法时按 5 处理 |
| `清理所有维度` | `true` | 为 `false` 时只清理主世界，但触发判定仍按三世界合计 |
| `输出统计日志` | `false` | 每轮统计都把主世界/下界/末地数量与合计写入控制台 |
| `控制台指令` | `["drop_cleanup", "掉落物清理"]` | 控制台触发词列表，可自定义 |

配置在插件 preload 阶段读取，修改后需要 `reload` 才会生效。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 控制台 | `drop_cleanup status` | 无 | 统计三维度掉落物数量并显示合计与阈值，不执行清理 |
| 控制台 | `drop_cleanup count` | 无 | 代码同样接受，行为与 `status` 相同 |
| 控制台 | `掉落物清理 status` | 无 | 使用默认配置里的第二个触发词 |

只写触发词、不带子命令时按 `status` 处理；子命令不是 `status` / `count` 时打印用法提示。本插件没有聊天栏或群聊指令。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）；
- 仅使用标准库（`threading`、`json` 等）与 ToolDelta 内置 API，无第三方库；
- 依赖服务器允许执行 `/execute in <维度> run testfor` 与 `/kill`；
- 统计、清理分别有 4 秒、5 秒超时，服务端卡顿时可能本轮跳过清理。

## 版本记录
- `1.0.0`（2026-11-21）：新增自建插件；每 5 秒统计三世界 `item` 实体，合计超过 600 时清理三个维度。
- `1.0.1`（2026-11-22）：单个维度的 `testfor` 超时改为按“未知”处理，本轮不清理、下一轮重试，不再每 5 秒输出一条扫描异常；统计超时 2→4 秒、清理超时 3→5 秒。
