# 进服验证 0.0.2
> 未验证玩家进服即踢出，到指定 QQ 群发送 `#验证 <编号>` 后放行。

收录自 ToolDelta 官方插件市场，原作者 `大庆油田`；本仓库有标准化修改。

## 功能
- 玩家进服时检查白名单：XUID 已在 `白名单` 中的玩家直接放行；不在白名单的玩家会生成一个 **6 位数字验证码** 并记入数据文件，然后用 `kick "<玩家名>" ...` 将其踢出，踢出原因里带群号和 `#验证 <编号>`。
- 监听本仓库 `群服互通云链版` 广播的 `群服互通/链接群消息`；群消息以 `#验证` 开头时，取空格分隔后的第二个字段作为验证码。
- 验证码有效时，把该验证码对应的 XUID 加入白名单、删除验证码与时间记录，并在群里回复 `验证成功，可以重新进服了`；无效或已过期时回复提示。
- 验证码 **10 分钟内有效**、只能使用一次；每次生成/处理验证码时会顺带清理过期记录。
- 白名单按 XUID 记录，玩家改名不影响；验证码与 XUID 的对应关系保存在数据文件里，ToolDelta 重启后仍可继续验证。
- 白名单只增不减，目前没有内置的移除指令，需要手动编辑数据文件。
- 配置 `用于接收验证的群` 为 `0`（默认）时不生效：只打印提示，不获取群服互通 API、不监听广播、也不踢人。
- 若配置的验证群与 `群服互通` 的「链接的群聊」不一致，自动改用群服互通的链接群并在控制台提示。

## 前置插件
| 插件 ID | 最低版本 | 用途 |
|---|---|---|
| `群服互通` | 0.0.8 | 提供 `群服互通/链接群消息` 广播和 `sendmsg()` 发群消息 |

`datas.json` 的 `plugin-id` 是 `PlayerJoinverify`。本仓库配套实现为 `群服互通云链版/`（`plugin-id` = `群服互通`，版本 `0.3.1`）；未加载 `群服互通` 时控制台打印 `未找到 群服互通，群内验证功能不可用`，验证流程整体停用（不会踢人）。

## 安装
1. 将 `进服验证/` 复制到实例的 `插件文件/ToolDelta类式插件/`；
2. 先确保 `群服互通云链版/` 已安装，并在其配置里设置好「链接的群聊」；
3. 到 `插件配置文件/进服验证.json` 填好 `用于接收验证的群`，再启动实例或在控制台执行 `reload`；
4. 也可以把本仓库添加为自定义插件市场源后直接安装。

## 配置
配置文件路径：`插件配置文件/进服验证.json`（首次加载自动生成）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `用于接收验证的群` | `0` | 踢出提示与验证结果发送的群号；`0` 表示未配置、插件不生效；应填写与 `群服互通` 的「链接的群聊」相同的群号，否则收不到验证消息 |

数据文件：`插件数据文件/进服验证/验证数据.json`（自动创建），结构为 `{"白名单": [XUID, ...], "验证码时间": {"<验证码>": 生成时间戳}, "<验证码>": "<XUID>"}`。

## 指令
| 位置 | 指令 / 触发词 | 权限 | 说明 |
|---|---|---|---|
| 群聊 | `#验证 <编号>` | 所有群成员 | 用踢出提示里的编号完成验证，成功后该 XUID 加入白名单 |

本插件没有控制台和聊天栏指令，只有上述群消息触发词。

## 依赖与兼容
- ToolDelta 1.3.7 类式插件（FateArk / MCSM 面板）。
- 本仓库改动：改为监听本仓库 `群服互通云链版` 的「群服互通/链接群消息」广播，不再依赖官方群服互通的内部列表；踢出指令使用玩家名；配置默认群号由官方写死的真实群号改为 `0`，未配置时不生效。
- 广播消息体形如 `{"QQ号": ..., "昵称": ..., "消息": ...}`；插件只读取 `消息` 字段，兼容字符串和「数组 + `type: text`」两种格式。
- 验证码为 6 位随机数字，10 分钟过期；同一秒多人进服不会互相覆盖。
- 踢人使用 `game_ctrl.sendwocmd()` 发送 `kick` 指令；验证成功/失败通过 `群服互通` 的 `sendmsg(群号, 文本)` 回复。
- 需要 `群服互通` 与本插件同时启用；群服互通未链接群或断线时收不到验证消息。
